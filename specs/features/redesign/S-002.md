# Slice S-002: When a person's device is set to dark mode, every page of the app opens in the dark theme.

Feature: [brief](brief.md)
Slice: 2 of redesign

## Outcome
When a person's device is set to dark mode, every page of the app opens in the dark theme; on a light device nothing changes.

## Rules

AC-72 Given a device set to dark mode,
      when any page renders,
      then `:root` declares `color-scheme: light dark` and the dark token values apply; native controls and scrollbars follow the theme.

AC-73 Given a device set to light mode, or a browser that reports no preference,
      when any page renders,
      then every token has its slice-1 value (AC-9) and the page looks as it did before this slice.

AC-74 Given the stylesheet,
      when its dark-mode rules are read,
      then they sit in `@media (prefers-color-scheme: dark)` and set custom properties (tokens) only, no other property; AC-10 still holds (no colour literal outside the token blocks).

AC-75 Given the theme,
      when a person wants to change it,
      then it follows the device setting only (Addendum 14): there is no switch, no cookie, no stored choice and no script for it.
