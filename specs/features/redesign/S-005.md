# Slice S-005: `.webp` files are served as `image/webp` on any machine, so that the home's art (slice 6) reaches the browser with its right type.

Feature: [brief](brief.md)
Slice: 5 of redesign

## Outcome
`.webp` files are served as `image/webp` on any machine, so that the home's art (slice 6) reaches the browser with its right type. The app picks a file's type from Python's type table, which reads the machine's own list of types on top of Python's built-in entries. Python 3.10's built-in entries have no `.webp`, and CI's runner did not add it, so closed #124's art was sent as `application/octet-stream`. nginx on sk24 passes every path to the app, so the app's type is the one the browser gets.

## Rules

AC-89 Given an app built while Python's type table holds only built-in entries without `.webp` (a machine whose own list of types does not know it),
      when a `.webp` file is served,
      then it is sent as `image/webp`, and the app's type table answers `.webp` with `image/webp`. The art is public and holds no personal data, so there is no owner and no 404 rule for another user.

AC-90 Given the same app,
      when the stylesheet, the script or any other file is served,
      then its type is what it was before this slice: `/static/betterjobs.css` is `text/css`, `/static/upload.js` a JavaScript type, and the table answers `.css`, `.js`, `.html` and `.ttf` as the built-in entries do. Only `.webp` is added.

## Out of scope
- **The art and its generator:** slice 6, a routine slice that brings closed #124's files (the 20 WebP images in `app/static/art/`, `gen/collage.py`, `gen/requirements.txt`).
- **Other types the built-in table lacks** (`.ttf`, `.woff2`): this slice changes no type but `.webp`, so the fonts are served as they are today; safe because nothing that works today changes; revisit if a browser refuses a font or the fonts move to woff2 (the fonts' weight, Owed for slice 7).
- **A version bump:** no page or URL changes, so `APP_VERSION` stays (its move to `app/version.py` is waived to slice 7, the home, in the plan's Owed).

## Touch points
- `app/main.py`: one line in `create_app`, next to the `/static` and `/fonts` mounts, `mimetypes.add_type("image/webp", ".webp")`, and its import.
- `CHANGELOG.md`: one line.
